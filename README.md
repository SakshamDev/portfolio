## 🚀 Getting Started

### Prerequisites
- Node.js (v18.17+ recommended)
- npm, yarn, or pnpm

### Installation
```bash
git clone https://github.com/SakshamDev/portfolio.git
cd portfolio
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
